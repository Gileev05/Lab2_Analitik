# Задание 2 — API-пайплайн

Данная работа представляет собой скрипт, написанный на языке JavaScript, который преобразует новость из CSV файла в краткий пересказ с помощью LLM (через Baidu), после чего сохраняет результат в текстовом файле.

# Запуск программы

1. Создать CSV файл с новостями
2. Открыть lab2.js и при необходимости поменять следующие пути:
  - `INPUT_CSV` - путь до файла новостей (по умолчанию `news.csv`)
  - `OUTPUT_FILE` - путь для создания результата (по умолчанию `summary.txt`)
3. Запустить программу с помощью IDE или в терминале командой `node lab2.js`

# Пример входных/выходных данных

Входной файл: `news.csv`:
